Run Amber in your browser

The real engine, compiled to WebAssembly and running on this page. Tables, qSQL, the join family and the backslash commands all work; nothing is installed and nothing leaves your browser.

Each line of the editor is evaluated in order, exactly as if typed at the prompt, and definitions persist between runs. Share copies a link with the code packed into it: whoever opens it sees your snippet run. The engine works in a background thread, so a long computation can be stopped.
